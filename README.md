# Ponto de Respawn - AOP2

Blog sobre Games desenvolvido para a disciplina **Programação Web - Front End**, da **Universidade de Vila Velha - UVV**.

**Autora:** Lara Silva de Almeida.  
**Ano:** 2026.

## Links

- [Site publicado](https://larrinha018-alt.github.io/AOP2/)
- [Repositório do trabalho](https://github.com/larrinha018-alt/AOP2)

## Como abrir

Baixe os arquivos pelo botão **Code → Download ZIP**, extraia a pasta e abra **index.html** no navegador. Todos os arquivos de imagem, CSS e JavaScript ficam no mesmo diretório e devem ser mantidos juntos.

## Páginas

| Página | Arquivo | Tema |
| --- | --- | --- |
| Home | index.html | Apresentação do blog e destaques com imagens e links |
| Universos | universos.html | Exploração e narrativa nos jogos |
| Em equipe | equipe.html | Cooperação e comunicação entre jogadores |
| Cena indie | indie.html | Criatividade e produção independente |
| Contatos | contatos.html | Responsável pelo blog e preparação de mensagens |

Todas as páginas usam HTML semântico e possuem `head`, `body`, `header`, `main`, `footer` e um menu de navegação com cinco links. Na Home, as imagens dos destaques levam aos artigos correspondentes.

## Tecnologias e recursos

- HTML em português brasileiro;
- CSS externo compartilhado, com layouts para computador e celular;
- JavaScript para menu móvel, filtros de leitura, cópia de links e preparação de mensagens;
- Ilustrações SVG originais, locais, com textos alternativos;
- Conteúdo editorial original sobre exploração, cooperação e jogos independentes.

## Página Contatos

O formulário prepara o texto de uma mensagem para o visitante copiar e compartilhar pelo canal combinado com a autora. Não há envio automático de e-mail nem armazenamento de dados em servidor. Esse comportamento está informado na própria página.

## Estrutura

- `index.html`, `universos.html`, `equipe.html`, `indie.html`, `contatos.html`: cinco páginas principais;
- `404.html`: página de erro;
- `styles.css`: estilos compartilhados;
- `script.js`: interações locais;
- `mundo.svg`, `equipe.svg`, `indie.svg`, `favicon.svg`: ilustrações e ícone.

O site não depende de instalação de bibliotecas ou de serviços externos para carregar seu conteúdo.
